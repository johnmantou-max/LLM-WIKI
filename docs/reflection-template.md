# 作業反思範本（請使用者在真實執行後填寫）

## 建 Wiki 時特別考量

- 我在內容深度與來源精確引用之間如何取捨？
- 哪些內容（例如 SMC 或交易所規則）因為來源不足而需要暫停？

## Graph / Loop 設計

- 我選擇固定的 Graph 節點，搭配每節點最多 3 輪修正。
- 最容易失敗的是哪一關？從實際執行報告擷取一個例子。
- 我將檢查移到哪一關？為什麼？
