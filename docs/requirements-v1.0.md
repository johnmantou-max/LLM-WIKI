# BTC Trading Wiki｜已確認需求 v1.0

## 十題訪談結果（2026-11-23）

1. **目標與讀者**：A，個人學習型，給本人查詢、深入學習與複習。
2. **領域**：BTC/區塊鏈基礎、K 線與 EMA/MACD/RSI、價格行為與 SMC（OB/FVG/流動性）、永續合約/槓桿/資金費率、Fed/CPI/美債/DXY、交易心理與風控，共六類。
3. **深度**：B，深入理解型：定義、原理、必要公式、圖表與交易案例。
4. **來源**：A，只接受使用者**手動提供**資料，禁止 AI 自動搜尋補資料。
5. **資料衝突**：B，並列觀點、來源、差異，不擅自裁決。
6. **引用**：C，重要論點/數據/公式提供精確來源與頁碼或章節/段落。
7. **匯入**：B，批次 ingest，自動去重及整理；同批源內異文不強行合併。
8. **檢查**：來源完整性、引用位置存在性、重複/矛盾、AI 幻覺、分類及內部連結，共五項。
9. **成果**：網頁 Wiki、HTML 教學簡報、Markdown 筆記、知識關聯圖；不做線上 AI 問答。
10. **Workflow**：C，Graph + Loop；Graph 固定階段，各階段 Loop 最多 3 輪，關鍵節點需人工確認。

## 已接受的實作提案

- 深色專業介面；可於 GitHub Pages 部署（靜態網頁）。
- 簡報 8–15 頁；從**通過審查的 Wiki**生成。
- `raw/` 來源不可改；Wiki 交叉引用與 log 持續維護。
- 程式檢查 ≠ 獨立 AI 語義審查。引用段落含義須另行人工/獨立 AI 確認。

## 未完成與阻塞條件（不可誤報）

- 使用者尚未在本新專案的 `raw/` 放入至少 5 篇可讀原始資料；來源連結、舊版 AI 摘要**不計入**本次手動匯入。
- 因資料未提交，尚無真實來源對照的六領域文章、正式講義簡報或完工檢查報告。
