## 4. Loop / Graph 的流程說明

Graph：受理指定來源 → 批次抽取 → 證據卡 → 整理 Wiki → 程式檢查 → 人工審核 → 產生網站與簡報 → 再檢查 → 交付。

Loop：單一節點中反覆「產生 → 檢查 → 修正 → 重檢」；最多 3 輪。出現原文不支持、引用失效或資料不足時停止，並退回最近的錯誤來源節點。
