## 原文小節：Features
- 【Features】SMC 工具包含 internal/swing 市場結構、BOS、CHoCH、看漲／看跌 Order Blocks、Equal Highs/Lows、Fair Value Gaps、前高前低與 premium/discount 區間。
- 【Features: Market Structure】BOS 與 CHoCH 是對市場結構變化的標示；大級別 swing 結構與小級別 internal 結構的標籤可能不同。
- 【Features: Order Blocks】Order Blocks 以價格區域方框標示潛在交易關注區，作者將其作為可能的確認進場區或目標區；不能藉由方框證實真有機構訂單。
- 【Features: Fair Value Gaps】Fair Value Gaps 用方框突出價格走勢中的不平衡區域；有門檻及時間框架等可調設定。
- 【Features: Equal Highs and Lows】接近的擺動高點與低點（EQH/EQL）是該指標標示的價格區域；不能直接認定一定有止損單在該處。
- 【Usage】BOS/CHoCH 可以協助辨識趨勢延續或可能的轉變，但是否有效仍取決於所用識別條件及市場背景。
- 【Conclusion】作者明確提醒：SMC 名稱與此類指標不保證存在機構或銀行級流動性，也沒有資料證明這套教學的有效性。
- 【應用界線】本篇是一位第三方指標作者的 SMC 方法描述，不是交易所逐筆委託簿或機構實際成交證據。
