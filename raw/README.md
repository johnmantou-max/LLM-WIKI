# 手動指定的網頁來源備註

本輪由使用者在對話中**親自指定**五個公開文章網址，因此 AI 獲授權查閱這些 URL。
`raw/01-05*.md` 是由已核實文章整理而來的**原創繁中摘要／來源筆記**，不是網站全文下載件，也不等於完整原文 ingest。
每項摘要標示原文所在章節；精確引用 p1:Lx 只定位此筆記行，原文完整依據須點選原網址與章節核對。

為尊重版權，未再製完整外部文章。如教師要求每篇的原始全文實際匯入，請在確認授權後自行合法取得原文並置於 `raw/`，以新版本重跑 ingest。
本資料可供靜態 GitHub Pages 公開的是本站原創摘要與來源連結，不含第三方完整著作。
